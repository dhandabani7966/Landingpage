## 💻 Tech Stack

- **Framework:** React 19 + Vite 8
- **Language:** TypeScript 5.8
- **Styling:** Tailwind CSS v4 (`@tailwindcss/vite`)
- **Typography:** Sora (Headings) + Plus Jakarta Sans (Body) + JetBrains Mono (Specs)
- **Icons:** Lucide React
- **Build Output:** Static HTML/CSS/JS for deployment on Vercel, Netlify, or GitHub Pages.

---

## 🛠️ Local Development & Build

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Runs at `http://localhost:5173/` (and exposes on network interfaces if `--host` is specified).

### 3. Production Build
```bash
npm run build
```
Generates optimized static assets in the `/dist` directory.
